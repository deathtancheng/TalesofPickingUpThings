## v4.5.4 — 服务崩了会自愈，报错不再刷屏

**后端防崩 + 守护（"连不上后端"的根治）**
- 以前任何一个没接住的异步异常都会让 Web 服务**整个进程静默退出**——
  `game.bat` 是最小化启动的，窗口一闪谁也看不见，玩家只会看到
  战报里刷一排"连不上后端"。现在改成：异常记进 `logs/crash.log`，
  进程继续活着，游戏照常玩。
- `game.bat` 升级成**守护模式**：服务万一真死了，3 秒后自动拉起来，
  不用再手动双击。运行日志在 `logs/web-out.log`。
- `stop.bat` 修了个配套 bug：原来只按端口杀，守护循环 3 秒后又会把
  服务拉起来——现在会先把守护窗口关掉，再停端口。

**报错折叠**
- 服务不在时每个动作的 catch 都会往战报里塞一行一模一样的
  "连不上后端"，瞬间刷屏。现在同样的文案 10 秒内只记一次，
  服务恢复后自动放行。

## v4.5.3 — 摄像头不闪了、NPC 场景不再撞车、标题屏改版、挨打的是主角

**摄像头：彻底修掉"闪 + 用不了"**
- 上一版快照兜底是每 250ms 直接改 `<img>.src`——旧图先清屏、新图还没到，
  所以一闪一闪根本没法看。现在改成**快照泵**：后台 fetch 一张完整 JPEG、
  转成 blob URL 之后再换图，换上去的永远是完整一帧，天然不闪；
  抓完一张立刻抓下一张，帧率自己跟着机器走（快的机器能有 8-10 fps）。
- 检测轮询连续失败 3 次才把取景框标灰——单次网络抖动不再让取景框闪灭。
- MJPEG 流直接放弃（实测太多环境"有流无画"），从起画面的第一步就走稳的那条路。

**三个 NPC 房有了自己的场景**
- 游方郎中 / 说书人 / 传功人不再借行脚商、借宿、铜镜间的图——
  新画了三张同风格的水墨场景：药摊（艾草 + 百子柜）、荒废书场（醒木折扇 + 条凳）、
  静室（蒲团 + 香炉 + 屏风）。进哪个门是哪幅画，不再撞车。

**标题屏：对齐 galgame 版式**
- 整屏主视觉立绘（新画的：蓑衣旅人提灯立于旧宅前，妖物剪影在雾里），
  左上家印 + 题字 logo，左侧竖排菜单（图标 + 大字 + 小注），
  悬停整条亮起并向右迎一步，左下角显示当前存档处境与周目。

**掉体力时动的是主角，不是妖物**
- 以前旅人掉体力只有血条闪一下，玩家看到的是右侧妖物扑过来、
  自己毫无动静，还以为扣血的是妖物。现在墨弹落地时**左边的旅人立绘
  会晃一下、泛一层红**（右栏形象卡同步），摸黑赶路的暗扣也会让主角晃。
  妖物前扑保留——那是"它出手"的演出，现在两头都动，谁挨打一目了然。

## v4.4.6 — 没一击打死迷宫妖物不再死锁

**症状**：白天迷宫里砸妖物，第一次没砸死——场景自己合上了，妖物还堵着门：
走不走动、回阁回不去、也没有再打的入口，整格死锁。

**根因**：服务端妖物房只有"初次进房"那个分支才返回 `needOffering` 和妖物
最新血量；"砸了但没死"的返回里两个都没有。前端一看：没解决、没等举物、
没抉择、没货单——按兜底逻辑给了个「继续」把场景合上，入口就此消失。

**修法**：
- 服务端：妖物没倒时，结果里带上 `foe`（最新血量）和 `needOffering`，
  场景保持展开，接着举下一件东西砸它；
- 前端双保险：场景选项把"妖物还活着"直接视作等待举物，不再依赖单一字段；
  SSE 断线重连（服务重启）后的第一份快照会清掉过期的本地场景态，
  服务半路挂掉重启也不会再把你关在旧场景里。

## v4.4.5 — 夜战妖物面板防压扁 + 工作台聊天修复

**夜战**：立绘 + 血条那块（妖物面板）被压成一条缝，架势条、旅人卡都好好的，
就它没了，连滚动条都不出。根因是 `.night-panel`（flex 纵列 + max-height:52vh）
内容超高时子项按比例收缩，而妖物面板自带 `overflow:hidden`——规范里这种
子项的自动最小尺寸是 0，压缩全让它一家扛了；缩完总高正好凑满 52vh，
overflow 不触发，滚动条也不来。现在夜战面板的直接子项一律 `flex:none`
（按内容站住），超高交给面板自己的滚动条。

**工作台**：聊天必报 `ndjson is not defined`。`src/agent/run.js` 用了
`ndjson()` 读 Ollama 的流式返回，但这个函数是 `tools.js` 的私有函数，
既没导出也没导入——服务端一抛错，聊天界面就挂红条。现在正常导出/导入。

## v4.2.0 — 宅子在动 · 走过的路不算数

- 什么也没有（但你还是记住了位置，因为这片宅子会动）

强度刻意压在正式房间之下：这是路上的零碎，不是每三步一场架。

**兼容性**

- **通关配装榜**：通关时把装备、咒术、数值、回合数存进跨局存档，
  结算弹窗直接跟上一局对比
